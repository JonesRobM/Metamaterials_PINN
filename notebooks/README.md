# Notebooks

Standalone PINN tutorials kept for reference. They are self-contained and do
**not** depend on, or feed into, the SPP metamaterial pipeline in `src/`:

- `Test_PINN.ipynb` - minimal PINN sanity check.
- `PINN_Gauss.ipynb` - PINN for Gauss's law / electrostatics.
- `PINN_Lossy_Line.ipynb` - PINN for a lossy transmission line.
